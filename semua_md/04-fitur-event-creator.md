# Fitur Lengkap untuk Event Creator

---

## 1. Autentikasi & Verifikasi

### 1.1 Daftar Creator
- Daftar sebagai Event Creator
- Isi data: Nama Organisasi, Email, No HP
- Upload KTP/NIK (verifikasi identitas)
- Upload NPWP (opsional, untuk pajak)
- Isi Rekening Bank (untuk penarikan dana)
- Status: Pending → Disetujui / Ditolak

### 1.2 Login
- Email + Password
- Google OAuth

---

## 2. Dashboard Creator

### 2.1 Overview
- Total event aktif
- Total tiket terjual (hari ini / bulan ini)
- Total pendapatan
- Saldo tersedia
- Notifikasi baru

### 2.2 Statistik
- Grafik penjualan per hari/minggu/bulan
- Tiket terjual per kategori
- Sumber traffic (dari mana pembeli datang)
- Demografi pembeli (kota, usia)

---

## 3. Buat Event

### 3.1 Info Dasar
- Judul event
- Deskripsi event (rich text editor)
- Kategori event (Konser, Festival, Teater, dll)
- Sub-kategori (opsional)

### 3.2 Media
- Upload poster utama (wajib)
- Upload banner tambahan
- Upload video trailer (opsional)
- Galeri foto event
- Banner untuk promosi (ukuran berbeda)

### 3.3 Jadwal
- Tanggal & waktu mulai
- Tanggal & waktu selesai
- Jam pintu buka (doors open)
- Multi-day event

### 3.4 Lokasi
- Pilih venue dari daftar / buat baru
- Alamat lengkap
- Google Maps integration
- Kota / Provinsi
- Koordinat GPS

### 3.5 Tiket & Harga
- Tambah kategori tiket (unlimited)
  - Nama kategori (GA, VIP, VVIP, Early Bird, dll)
  - Harga
  - Kuota
  - Deskripsi benefit
  - Minimal pembelian (untuk group)
  - Maksimal pembelian per transaksi
- Jadwal harga:
  - Pre-sale price
  - General sale price
  - Flash sale (harga + waktu)
- Aktifkan/nonaktifkan kategori tertentu

### 3.6 Syarat & Ketentuan
- Aturan event
- Kebijakan refund
- Aturan pembatalan
- Usia minimum (opsional)
- Dress code (opsional)
- Yang dibawa / tidak dibawa

### 3.7 Sponsor
- Tambah logo sponsor
- Link website sponsor
- Tingkat sponsorship (Platinum, Gold, Silver)
- Tampilkan di halaman event

### 3.8 Pengaturan Tambahan
- Batas umur pembeli
- Limit tiket per user
- Aktifkan waiting list (jika sold out)
- Aktifkan fitur transfer tiket
- Aktifkan fitur refund otomatis

---

## 4. Kelola Event

### 4.1 Daftar Event
- Semua event (Draft, Published, Completed, Cancelled)
- Quick filter: Aktif, Selesai, Dibatalkan
- Search event

### 4.2 Edit Event
- Edit semua informasi event
- Tambah/hapus kategori tiket
- Ubah harga & kuota
- Upload media baru

### 4.3 Publish / Unpublish
- Submit untuk review admin
- Simpan sebagai draft
- Unpublish (sembunyikan dari public)

### 4.4 Batalkan Event
- Alasan pembatalan
- Kebijakan refund (otomatis / manual)
- Notifikasi ke semua pembeli

---

## 5. Kelola Penjualan

### 5.1 Dashboard Penjualan Real-time
- Tiket terjual per jam
- Total pendapatan
- Tiket tersisa per kategori
- Order masuk (real-time)

### 5.2 Data Pembeli
- Daftar semua pembeli
- Filter: Kategori tiket, Status bayar, Tanggal
- Detail: Nama, Email, No HP, Tiket, Status
- Export ke CSV/Excel

### 5.3 Order Management
- Lihat detail order
- Status: Pending, Paid, Used, Refunded, Expired
- Batalkan order (opsional)
- Manual check-in (jika diperlukan)

---

## 6. Laporan

### 6.1 Laporan Penjualan
- Ringkasan total penjualan
- Breakdown per kategori tiket
- Grafik penjualan harian
- Pendapatan bersih (setelah potongan)

### 6.2 Laporan Keuangan
- Total pendapatan
- Potongan platform (komisi)
- Pajak (PPN, Pajak Hiburan Daerah)
- Pendapatan bersih yang bisa ditarik
- Riwayat penarikan dana

### 6.3 Export
- Export ke CSV
- Export ke PDF
- Export ke Excel

---

## 7. Kode Promo & Voucher

### 7.1 Buat Promo
- Kode voucher (custom atau auto-generate)
- Tipe: Persentase diskon / Nominal tetap
- Berlaku untuk: Semua tiket / Kategori tertentu
- Kuota penggunaan
- Minimal pembelian
- Tanggal berlaku (start - end)
- Kombinasi dengan promo lain (boleh/tidak)

### 7.2 Kelola Promo
- Edit promo
- Aktifkan/nonaktifkan
- Hapus promo
- Lihat statistik penggunaan

---

## 8. Penarikan Dana (Withdraw)

### 8.1 Proses Withdraw
- Lihat saldo tersedia
- Masukkan jumlah (minimal Rp 100.000)
- Pilih rekening tujuan
- Submit request

### 8.2 Status Withdraw
- Pending → Diproses → Transfer → Selesai
- Riwayat penarikan
- Estimasi waktu transfer (1-3 hari kerja)

---

## 9. Komunikasi

### 9.1 Kirim Notifikasi ke Pembeli
- Email blast ke semua pembeli
- Kirim update jadwal/perubahan
- Kirim reminder sebelum event

### 9.2 Chat dengan CS Platform
- Hubungi tim support ConcerTIX
- Lihat tiket support
